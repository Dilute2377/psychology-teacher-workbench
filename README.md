# 心理老师工作台

面向学校心理教师的纯本地、离线优先工作台。当前源码版本为 **1.1.1**，覆盖学生综合档案、个体咨询 SOAP、心理普查、团体辅导、教学工作台、工作留痕与协同、重点学生总表、加密备份和 PDF 台账导出。

> 本项目不附带学生、咨询、普查或工作留痕示例数据。首次使用请先完成安全设置、学校与学期配置，再导入或新增真实业务数据。心理评估与危机干预仍须依据学校专业流程和临床标准执行。

## 主要能力

- **概览面板**：本学期咨询人次、初访/复访、可配置的危机评级分布、实时在册/历史累计人数、全校健康率、问题归因和心理健康周/月报打印导出。
- **动态危机评级体系**：首次引导或“系统设置 → 预警体系配置”可选择一级或三级最高危口径，并自定义等级别名；概览、档案、咨询、总表和 PDF 导出实时统一。
- **学生档案**：全局搜索、学号唯一校验、在读/历史学籍、风险历史、服务履历、医疗就诊与会谈附件预览。
- **重点学生与个案总表**：自动归集红/橙/黄预警学生与个案辅导学生，支持等级、年级、班级、姓名/学号筛选，并导出脱敏总表或单人完整卷宗。
- **个体咨询**：SOAP 记录、初访/复访、普查约访、问题分类、观察词模板、当次风险快照和预约提醒。
- **心理普查**：MHT、SCL-90、PHQ-9、GAD-7、SDS、SAS 导入，预警原因和因子得分可追溯到学生档案。
- **团体辅导与教学工作台**：团辅成员、教案库、课程进度大盘、单双周课表、课堂观察和备课素材库。
- **工作留痕与协同**：家长沟通、班主任协同、领导指令、任务交接、代课杂务、危机免责存证及本地附件。
- **安全与数据治理**：首次安全誓约、AES-256-GCM 加密备份、主密码/恢复码、自动静默备份、覆盖/合并恢复、500 人 Mock 压测、仅清理 Mock 和恢复出厂。

## Windows 桌面版

无需安装 Node.js。前往 [GitHub Releases](https://github.com/Dilute2377/psychology-teacher-workbench/releases) 下载 Windows 安装版或便携版。安装版适合固定电脑，便携版适合临时或移动使用；两者的 IndexedDB 数据彼此隔离。

运行前请确认：

1. 首次启动设置 4–16 位数据加密主密码，并抄写只显示一次的 24 位恢复码。
2. 在“系统设置 → 学校与教学配置”选择学段、年级班级数和作息。
3. 在“系统设置 → 学期与升学”新增并设为当前学期。
4. 在“学生档案”导入名单或逐个新增学生。

如果双击后闪退：

1. 不要先打开心理老师工作台。
2. 从 Releases 下载 `psychology-teacher-workbench-startup-diagnostic-1.1.1.zip` 并解压。
3. 双击其中的 `startup-diagnostics.bat`。
4. 工具会自动定位或让你选择已经安装的“心理老师工作台.exe”，然后自动启动并观察约 10 秒。
5. 将桌面生成的“心理老师工作台-启动诊断-日期时间.txt”发给技术支持。

诊断工具不会读取学生资料、附件、备份、主密码或恢复码。

## 从源码运行

需要 Node.js 20+ 和 npm：

```bash
npm install
npm run dev
```

生产构建与 Windows 打包：

```bash
npm run build
npm run package:win
```

打包使用 Electron ASAR 和最高压缩，输出 NSIS 安装版与 portable 便携版到 `release/`。发布前请执行：

```bash
git diff --check
```

## 日常工作路径

### 迎接来访或紧急接访

顶栏搜索学生姓名/学号，进入档案后点击“新增咨询”，填写 SOAP、当次风险等级和后续计划。保存后，咨询历史、服务履历和概览统计会同步更新。

### 普查后批量跟进

在“心理普查”导入 `.xlsx`/`.csv`，查看因子得分和预警原因；在批次明细点击“档案”或“约访”，进入学生档案或预填普查约访咨询。

### 迎检前导出台账

在概览面板点击“导出心理健康周/月报”；在重点学生总表按当前筛选导出脱敏汇总；在单个学生档案点击“导出单人完整档案卷宗（PDF）”。所有打印均在当前页 Modal 内完成，不打开新窗口。

## 附件与存储边界

- 学生就诊附件支持 PDF、JPG、JPEG、PNG；图片进入 IndexedDB 前会自动缩放压缩。
- 工作留痕和家校沟通附件支持图片、音频、视频及普通文件；音频/视频和其他内嵌附件默认不超过 30MB。
- 超过 30MB 的音频/视频会被阻止并提示优先使用本地路径引用，避免 Base64 让应用内存持续膨胀。
- 备课素材单个文件不超过 8MB，图片同样会自动压缩。
- 浏览器无法安全提供真实本地路径；如需保存大型录音/视频，请在留痕正文中记录脱敏后的本地路径或文件名，并定期导出加密备份。

## 加密备份与恢复

“系统设置 → 数据备份与恢复”支持全量 `.mindbag` 备份。备份包含业务表和必要配置，使用 AES-256-GCM 加密；Electron 版可以选择目录静默落盘，Web/开发版回退为浏览器下载。

恢复流程为：选择 `.mindbag`/`.json` 文件 → 查看文件摘要 → 输入主密码或 24 位恢复码 → 选择覆盖恢复或合并恢复。恢复写入前会剥离响应式 Proxy 和不可结构化克隆值，避免 `DataCloneError`。

建议在换电脑、学期结束、导入大量数据前后各导出一次。不要把 `.mindbag`、学生附件或含个案信息的截图上传到公开网盘、Issue 或聊天群。

## 开发测试与 Beta

开发者可在“系统设置 → 数据备份与恢复”使用 500 人 Mock 数据生成、仅清理 Mock 和恢复出厂功能；恢复出厂前必须输入 `RESET`，并建议先导出备份。

需要真实试用的老师请使用虚构或脱敏数据，参阅 [Beta 真机实战测试包](./docs/BETA_TESTING.md) 中的 7 天流程和每日反馈模板。完整模块说明见 [完整使用说明书](./docs/USER_GUIDE.md)。

## 隐私与合规

业务数据默认保存在当前设备的 IndexedDB；飞书提醒只有在老师主动配置 Webhook 后才会发送。数据锁 PIN、加密主密码和恢复码均由使用者保管，项目维护者无法代为找回。软件是教学管理与工作留痕辅助工具，不替代心理诊断、危机评估、转介和学校应急处置流程。

## 技术栈与目录

Vue 3 · Vite · TypeScript · Tailwind CSS · Pinia · Dexie/IndexedDB · SheetJS (`xlsx`) · Electron

```text
src/
├─ components/   # 业务组件、表单、抽屉与弹窗
├─ db/           # Dexie 数据库定义与版本迁移
├─ services/     # 备份、加密、附件边界、学生、提醒与导出服务
├─ stores/       # Pinia 响应式状态
├─ views/        # 概览、学生、咨询、普查、教学和设置工作区
└─ utils/        # 年级、量表解析、Mock 数据和交互工具
electron/
├─ main.cjs      # Electron 主进程与备份目录 IPC
└─ preload.cjs   # Context Isolation 安全桥接
```
