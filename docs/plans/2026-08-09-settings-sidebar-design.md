# 系统设置左右双栏导航设计

## 目标

将系统设置从顶部横向 Tab 改为左右双栏布局，消除 8 个入口挤在一行导致的横向滚动，同时保留现有设置表单、数据逻辑和 activeTab 路由内状态。

## 设计

- 左侧固定约 240px 的设置目录，使用三组纵向菜单：基础与教学配置、预警与规则、系统与安全。
- 右侧为 `flex-1` 表单画布，顶部展示当前入口标题和一句说明，下面渲染现有设置内容。
- 选中态使用 emerald 色背景、文字和右侧边框；未选中项保持低对比度文字与悬停背景。
- 桌面端保持左栏完整可见；窄屏时目录压缩为顶部可滚动的紧凑菜单，避免挤压右侧表单。
- 使用 Lucide 图标，不新增数据库字段，不改变任何业务逻辑。

## 验证

- `npm run build`
- `git diff --check`
- 人工检查设置入口切换、备份弹窗、评级配置保存和 768p/1080p 可见性。
