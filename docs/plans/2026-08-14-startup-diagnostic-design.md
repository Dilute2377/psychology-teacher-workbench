# 启动闪退一键诊断工具设计

## 目标

为没有电脑基础的用户提供一个独立的一键诊断工具。用户只需双击启动，不需要先打开工作台，也不需要操作 Windows 事件查看器；工具自动尝试启动工作台、观察启动结果并生成可发回技术支持的文本报告。

## 方案

- 使用一个中文命名的 `.bat` 作为用户入口，避免 PowerShell 执行策略和命令行操作。
- 由 `.bat` 调用同目录的 PowerShell 脚本；脚本不需要管理员权限。
- 优先检查常见安装路径和诊断工具同目录，找不到时弹出文件选择框，让用户选择工作台 EXE。
- 启动目标程序并观察约 10 秒，记录“正常运行 / 观察期内退出 / 启动失败”。
- 读取最近一段时间的 Windows 应用程序错误事件，仅保留与目标程序、Electron、Application Error 或 Windows Error Reporting 相关的条目。
- 将用户名和用户目录替换为 `<用户目录>`，不读取 IndexedDB、附件、备份、密码、恢复码或飞书配置。
- 在桌面生成 `心理老师工作台-启动诊断-时间.txt`，完成后自动打开所在文件夹。

## 交付与验证

- 两个脚本纳入源码仓库，便于后续维护和审查。
- 额外打包为 ZIP 上传到现有 `v1.1.1` 发布页，用户下载后解压并双击 `.bat`。
- 使用本机 PowerShell 运行语法检查；检查脚本能生成报告、能处理找不到 EXE 和进程未退出两种分支。
- 本功能不改变应用版本号和业务数据。
