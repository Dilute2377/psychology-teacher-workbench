# 课程结案异常学生跨班搜索修复设计

## 问题

教学记录的课程进度大盘顶部“教案速览”入口只传入教案，没有传入年级和班级。结课登记抽屉中的候选学生筛选却强制要求 `grade` 和 `className` 同时匹配空字符串，导致列表始终为空，姓名/学号输入看起来像失效。

## 方案

- 从具体班级卡片进入时传入单一 `{ grade, className }`，候选学生范围锁定为该班在读学生。
- 从进度单元顶部进入时传入该单元关联的所有年级/班级，默认跨关联班级搜索。
- 顶部入口增加可选班级筛选，默认“全部关联班级”，不要求老师先选班级。
- 搜索同时匹配姓名和学号，并做大小写无关的标准化处理。
- 切换入口、教案单元或可选班级时清空搜索词和已选异常学生；保存时如果跨班选择了学生，提示按班级分别登记，避免一条课程记录混入多个班级。
- 使用学生的当前推导年级，并兼容旧档案中的保存年级字段，避免历史数据因年级迁移导致无法匹配。

## 数据流

`CourseProgressMatrix` 产生入口范围 → `TeachingWorkspace` 组装抽屉上下文 → `LessonLogDrawer` 计算候选学生 → 选择学生后按实际班级保存结课记录。

## 验证

1. 具体班级卡片：只能看到本班学生，姓名和学号均可搜索。
2. 顶部教案速览：未选择班级时可跨所有关联班级搜索。
3. 顶部入口选择班级后只显示该班学生。
4. 切换班级或重新打开抽屉后，搜索和已选学生为空。
5. `npm run build` 与 `git diff --check` 通过。
