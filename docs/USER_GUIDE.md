# 心理老师工作台使用说明书

心理老师工作台是一套浏览器本地运行的学校心理工作工具。它不依赖云端业务数据库；学生档案、咨询 SOAP、普查数据、附件证据与教学记录默认留在当前设备的浏览器中。

## 第一次使用

### 1. 配置学校和班级

进入“系统设置 → 学校与教学配置”。

1. 选择一个学校学段：小学、初中或高中。
2. 为每个启用年级填写最大班级数。系统会自动生成 `1班` 到指定班级数的选项。
3. 设置上午、下午节数、每节课时长和具体上课时间。
4. 点击“保存教学配置”。周课表会按保存后的课时数量重建网格。

年级选项来自内置 K-12 顺序，不会因某个年级暂时没有学生而消失。

### 2. 新建当前学期

进入“系统设置 → 学期与升学”，点击“管理与新增学期”。填写学年、学期序号和起止日期，然后设为当前学期。顶部学期选择器可以随时切换当前工作学期。

建议先创建学期，再导入学生与录入业务记录；咨询、普查、团辅、教学记录都会保存关联的 `termId`。

### 3. 导入学生

进入“学生档案”，点击“导入”。下载模板后填写学号、姓名、性别、班级、紧急联系人、联系电话和标签。上传后先检查预览中的必填项与重复学号，再确认写入本机数据库。

导入的新生会按当前学年自动推导入学年份和初始年级。也可以点击“新增学生”逐个建立档案。

## 总览与学期

“概览面板”用于查看当前学期的咨询人次、危机预警与重点关注人数、在读学生数及咨询问题归因。左侧预警学生可以直接跳转到对应档案。

切换顶部学期后：

- 概览统计、咨询列表、普查批次和教学记录会切换到该学期。
- 学生显示年级会根据入学年份和当前学年自动计算。
- 学生档案内的服务履历、咨询历史和普查历史仍保留全历史，不会被当前学期截断。

## 学生档案

### 列表与筛选

学生档案列表支持姓名、学号、标签搜索，以及年级、班级、危机预警等级组合筛选。可切换按危机程度升序或降序排序，优先处理风险较高的学生。

默认仅显示在读学生；勾选“包含非在读学生”后，可检索已转出、休学和已毕业档案。

### 档案页面

点击学生卡片后，右侧展示综合档案：

- **服务履历**：自动汇总个体咨询、心理普查、团体辅导、课堂观察和关联工作留痕；点击节点查看详情。
- **咨询历史**：按时间倒序展示 SOAP 卷宗，最新记录默认展开。
- **普查数据**：展示历次量表得分、预警结论和同量表的跨轮次趋势。
- **工作留痕**：展示关联该生的沟通、指令、交接或危机免责证据。
- **档案编辑**：可修改班级、联系方式、标签、学籍状态和危机预警等级。

### 特殊学籍与升学

学生以 `enrollmentYear` 推导年级。需要留级、降级或其他特殊处理时，在档案编辑中开启“手动指定当前年级”，填入实际年级。开启后，一键升学不会覆盖该学生的人工决定。

学籍状态可设置为在读、已转出、休学或已毕业。日常列表默认隐藏非在读学生，但历史档案和服务记录始终保留。

## 个体咨询与 SOAP

进入“个体咨询”后，左侧可按学生姓名/学号、问题分类和来访类型筛选。点击记录查看详情，点击“新增咨询”开始录入。

### 新增咨询

1. 选择学生。系统会带出当前年级、班级、危机预警等级，并计算“第 N+1 次”咨询。
2. 填写日期、时长、来访类型和问题分类。
3. 如需预约提醒，填写预约日期时间。
4. 在 S、O、A、P 四段录入内容；每段都可以插入或编辑本机保存的模板。
5. 在 O 段可点击常用观察词快速追加；词库可在系统设置维护。
6. 若本次评估改变风险等级，选择新的危机预警等级后保存。

保存后，咨询记录会写入本机数据库、同步学生风险等级，并立刻出现在该生的服务履历和咨询历史中。

## 心理普查

“心理普查”以批次管理每一次测评。左侧选择批次，右侧查看人数、预警比例、异常因子统计和学生明细。

### 导入普查表

1. 点击“导入新普查数据”。
2. 选择量表类型：MHT、SCL-90、PHQ-9、GAD-7、SDS 或 SAS。
3. 上传 `.xlsx` 或 `.csv` 文件，并检查系统识别的学号、姓名、班级与因子列。
4. 设置或确认预警规则，预览未匹配学生与预警结果。
5. 确认导入。

系统依据学号关联学生档案；可选择为未匹配学号建立最小学生档案。导入成功后，普查结果自动写入该学生的“普查数据”和“服务履历”。

### 预警跟进

在批次详情中，可按年级、班级、预警状态、姓名或学号筛选。因子分以中文标签显示，超标项高亮。点击“快捷约访”会直接打开新增咨询，并预填学生、普查约访类型、关联问题分类和 S 段背景。

## 团体辅导

团体辅导用于记录一次活动与多位学生的共同参与。

1. 点击“新增团辅”，填写主题、期数、日期、时长、地点与过程纪要。
2. 通过年级、班级、姓名或学号筛选候选学生，加入已选成员区；可批量添加当前班级。
3. 在成员观察折叠区，按需要为个别成员填写观察。
4. 保存。

团辅只保存一条原始活动记录。每一位已选成员的服务履历都会动态显示该团辅节点；从节点或成员徽章可跳回详情和学生档案。

## 工作留痕与协同

该模块用于家长沟通、班主任协同、领导指令、任务交接、代课杂务和危机免责存证。

### 新增留痕

1. 选择分类并填写精确到分钟的发生时间。
2. 填写对接人、主题和详细过程。
3. 根据需要开启“关联特定学生”，搜索并选择学生。
4. 可拖入图片、音频、视频或文件作为本地证据；列表中可移除附件。
5. 如需提醒，开启“设定飞书定点提醒”并填写提醒时间。
6. 保存后，新增记录会被高亮选中；若关联学生，也会进入该学生的工作留痕和服务履历。

详情抽屉支持图片放大、音频播放和视频播放。

## 教学记录与教学工作台

“教学记录”左侧是心理教案库，右侧有三项工作区。

### 心理教案库

用于新建、编辑、删除可复用教案。教案不锁定年级班级；可拖拽到进度大盘或周课表进行安排。

### 课程进度大盘

1. 点击“新增进度单元”，选择教案和授课年级。
2. 展开某个年级标签查看所有班级的进度卡片。
3. 点击“标记已上课”即可手动完成或撤销完成状态。
4. 如果班级已有周课表时间，卡片会显示对应时段。
5. 可移除某个年级标签或归档整条进度单元。

### 心理周课表

课表按照系统设置的节次数生成完整周一至周五网格。

- **看课表**：只读全览，展示每周、单周和双周课程。
- **仅单周**：只显示每周与单周课程，可从空位添加单周课程。
- **仅双周**：只显示每周与双周课程，可从空位添加双周课程。

在可编辑视角点击空位的加号，选择班级和教案。已安排课时可更换教案、取消关联或彻底清除槽位；结课打勾会同步到课程进度大盘。毕业班会自动排除在教学班级范围外。

### 备课素材库

用于存放视频、互动游戏、案例图解、小测量、PPT 与讲义等零散资源。素材可填写说明、链接、标签或本地附件；支持预览、删除，并可引用到教案或具体课时。

### 课堂观察

结课登记或新增教学记录时，可以标记异常学生并填写观察。保存后，观察会作为 📚 节点进入对应学生的服务履历；老师可从节点快捷发起教师转介咨询。

## 系统设置

系统设置包含以下页签：

- **学校与教学配置**：学段、每个年级班级数、作息、单双周模式。
- **问题分类与词库**：维护咨询问题分类与 SOAP 常用观察词。被历史咨询引用的分类不能删除。
- **学期与升学**：新增、切换和安全删除学期；使用一键升学向导批量推进在读学生并归档毕业生。
- **安全与锁屏**：设置或修改 4–6 位本机 PIN，随时锁定屏幕。
- **数据备份与恢复**：导出或恢复 `.mindbag`。
- **飞书通知机器人**：配置 Webhook、提醒时间与测试卡片。
- **关于系统**：再次查看免费公益声明和作者信息。

## 数据锁、备份和恢复

### 数据锁

点击顶栏“数据锁”，首次使用需设置 4–6 位 PIN。锁屏只遮盖页面，不会清除当前路由、选中学生或未保存的浏览上下文。

### 导出备份

点击顶栏“备份”或系统设置中的导出按钮。生成 `.mindbag` 文件，内容包括当前 IndexedDB 的业务表、附件和本机配置。

建议在导入大量数据、学期末、换电脑前各导出一次。不要将备份文件上传到公开网盘或发送给无关人员。

### 恢复备份

选择 `.mindbag` 或 `.json` 文件后，系统会校验格式并展示摘要。

- **覆盖恢复**：清空当前本地数据后还原备份，适合新电脑迁移或回退。
- **合并恢复**：按记录 ID 去重合并，适合补回缺失记录。

确认后系统会刷新页面，以重新加载最新本机数据和配置。

## 飞书提醒

飞书功能需要先在飞书群中创建自定义机器人，获得 Webhook 地址。

1. 进入“系统设置 → 飞书通知机器人”。
2. 填写 Webhook；如机器人开启了签名校验，再填写签名密钥。
3. 开启总开关并按需配置：咨询提前提醒、心理课提前提醒、每日工作汇总和工作留痕提醒。
4. 点击“发送测试卡片消息”验证连接。

提醒检查在页面运行期间每 30 秒执行一次。关闭浏览器或工作台页面时，本地浏览器不能继续执行提醒；如需全天候通知，需要后续部署桌面常驻或服务器端提醒服务。

## 数据联动规则

- 修改学生风险等级后，学生列表、学生头部和概览预警统计会响应式更新。
- 保存咨询后，档案服务履历、咨询历史和累计咨询次数会同步更新。
- 导入普查后，普查结果、预警信息和服务履历会同步更新。
- 保存团辅后，所有成员的服务履历会出现同一条团辅节点。
- 保存课堂观察或学生关联工作留痕后，对应学生档案会出现相应节点。
- 一键升学会更新学生学籍状态；开启人工年级覆盖的学生不受自动公式影响。

## 常见问题

### 为什么换浏览器后看不到数据？

业务数据默认存于浏览器 IndexedDB。换浏览器、清理网站数据或换电脑前，请先导出 `.mindbag`，再在新环境中恢复。

### 为什么当前学期没有记录？

咨询、普查、团辅和教学主列表默认按顶部当前学期过滤。检查顶部学期是否正确；学生档案内的全历史页签不受此限制。

### 为什么不能删除某个学期或分类？

系统会保护已有历史引用。有关联业务记录的学期、已被咨询引用的问题分类不能直接删除，以防档案无法追溯。

### 飞书为什么没有收到提醒？

检查总开关、Webhook、签名密钥、浏览器页面是否保持运行，以及预约/课表/留痕的时间是否已经填写。先使用测试卡片确认机器人连接。

### 如何从零开始清空本机数据？

先导出备份，再使用浏览器的网站数据管理功能清除本地站点数据。清除后重新打开应用，按“第一次使用”重新配置学校、学期和学生。
