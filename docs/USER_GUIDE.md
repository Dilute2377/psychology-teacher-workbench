# 心理老师工作台｜完整图文使用说明书

> 适用版本：**1.1.1**
> 适用对象：学校心理教师、心理健康指导中心、班主任协同人员
> 数据原则：业务数据默认只保存在当前设备，不依赖云端业务数据库。

这是一份可以直接交给老师使用、也可以继续制作成公众号图文教程的操作手册。文中所有“截图位”都已经标明了**应截取哪个界面、截取什么范围、放在什么位置、是否需要打码**。

## 先看这 5 条安全规则

1. 学生姓名、学号、联系方式、咨询 SOAP、就诊材料和录音视频都属于敏感信息；截图、导出和发公众号前必须脱敏。
2. 工作台是教学管理与工作留痕辅助工具，不替代专业心理评估、危机干预、转介和学校应急处置流程。
3. 首次启动设置的加密主密码和 24 位恢复码不会由项目维护者代为找回；恢复码只显示一次，必须离线抄写保存。
4. 更换电脑、浏览器或清理网站数据前，先导出 `.mindbag` 加密备份并确认文件可以恢复。
5. 不要把真实个案材料直接粘贴到第三方 AI 或公众号排版平台；公众号文章只使用虚构、脱敏或已经获得授权的内容。

## 二、先理解工作台界面

首次进入后，工作台分成四个区域：

1. **顶栏**：全局搜索框、当前学期选择器、数据锁、备份等全局操作。
2. **左侧导航**：概览面板、学生档案、个体咨询、心理普查、团体辅导、工作留痕与协同、教学记录、系统设置。
3. **中间列表与筛选区**：根据当前模块显示学生、咨询、普查批次、团辅、留痕或教案列表。
4. **右侧主工作区**：查看详情、填写表单、预览报告或编辑档案。

> **插入位置：** 本节之后。
> **截图来源：** 打开工作台后的“概览面板”。
> **截图范围：** 必须同时看到顶栏搜索框、左侧导航、概览标题和当前学期。
> **脱敏要求：** 使用虚构学生或空数据；不要显示真实姓名。

### 重要的“当前学期”规则

顶部学期选择器影响咨询、普查、团辅和教学主列表的统计范围。学生档案的服务履历、历史咨询和历史普查记录仍然保留全历史，不会因为切换当前学期而被删除。

## 三、第一次使用：从零配置到可以录入

### 3.1 完成安全设置

首次启动会阻止进入主界面，先显示安全设置弹窗。

**第一步：设置数据加密主密码**

1. 输入 4–16 位主密码。
2. 再次输入确认密码。
3. 两次一致后继续。

**第二步：保存紧急恢复码**

系统生成 24 位恢复码，例如 `K9X2-8PLM-7QWA-3VTN`。恢复码只显示一次，它用于在无法输入主密码时解密备份。

1. 使用纸笔抄写，或在学校批准的离线密码保管位置保存。
2. 不要把恢复码放在学生档案、公众号、微信群或普通截图中。
3. 点击“我已妥善保存，开启工作台”完成初始化。

### 3.2 配置学校、年级、班级和作息

进入 **系统设置 → 学校与教学配置**。

1. 选择学校学段：小学、初中或高中。
2. 勾选当前启用的年级。
3. 为每个年级填写最大班级数，系统会生成 `1班`、`2班` 等班级选项。
4. 设置上午节数、下午节数、每节课时长和具体上课时间。
5. 点击“保存教学配置”。

保存后，学生新增、学生导入、课程进度和周课表会使用这些年级与班级选项。年级不会因为当前没有学生而自动消失。

### 3.3 新建当前学期

进入 **系统设置 → 学期与升学 → 管理与新增学期**。

填写：

- 学年，例如 `2026-2027`；
- 学期，第一学期或第二学期；
- 开始日期和结束日期；
- 学期名称，建议使用系统生成名称；
- 点击保存，再将目标学期设为当前学期。

建议先完成学期配置，再导入学生、录入咨询、导入普查和安排课程。这样后续统计会自然落在正确学期。

### 3.4 建立学生档案

有两种方式：批量导入和逐个新增。

#### 方式 A：批量导入名单

进入 **学生档案**，点击中间列表顶部的“导入”。选择 `.xlsx` 或 `.csv` 文件。

导入前至少准备以下字段：

| 字段 | 是否建议填写 | 说明 |
|---|---:|---|
| 学号 | 必填 | 全校唯一；同名学生也必须用不同学号区分 |
| 姓名 | 必填 | 按学校正式名单填写 |
| 性别 | 建议 | 男、女或其他 |
| 年级 | 必填 | 必须来自学校配置 |
| 班级 | 必填 | 必须来自该年级的班级列表 |
| 联系人姓名 | 可选 | 监护人或紧急联系人 |
| 联系电话 | 可选 | 建议只录入工作需要的号码 |
| 快捷标签 | 可选 | 用逗号分隔，如“学业焦虑，人际敏感” |

导入时检查：

1. 表头是否正确；
2. 学号是否为空；
3. 是否出现重复学号；
4. 班级是否属于对应年级；
5. 同名不同学号是否被正确保留；
6. 预览中的有效条数和异常提示。

确认导入后，数据写入当前设备的本地数据库。导入失败时先根据提示修正表格，不要连续重复导入同一文件。

> **截图来源：** 学生档案 → 中间列表顶部。
> **截图范围：** 导入、新增、搜索、年级/班级/预警筛选。
> **脱敏要求：** 使用示例名单。

#### 方式 B：逐个新增学生

点击“新增”，填写姓名、学号、年级、班级、性别、初始预警等级、紧急联系人、联系电话和快捷标签，点击“保存学生”。

系统会拦截空白学号和重复学号。同名、同班、同性别学生只要学号不同即可新增。

## 四、全局搜索、筛选和删除后的正确操作

### 4.1 顶栏全局搜索

顶栏搜索框与学生档案、个体咨询、工作留痕页面的局部搜索同步：

1. 输入姓名、学号或关键词；
2. 在列表页，局部列表会即时过滤；
3. 在概览面板等没有列表的页面，按 Enter 会跳转到学生档案并带入关键词；
4. 可以使用 `Ctrl + K` 快速聚焦顶栏搜索框。

### 4.2 删除后的等待与检查

删除学生、咨询、团辅、教案、留痕或附件前，先确认对象和影响范围。删除完成后等待列表刷新，再进行下一次操作；如果页面仍然显示旧条目，先刷新页面，不要重复点击删除。

删除规则：

- 删除工作留痕会同步清理该条记录中的附件引用；
- 删除咨询不会自动删除学生档案；
- 删除团辅会同步移除成员履历中的团辅节点；
- 有历史业务引用的学期或问题分类会被保护，不能直接删除；
- 删除学生前应先导出或确认其档案是否仍需保留。

## 五、概览面板：每天先看这里

进入 **概览面板**，可查看当前学期和全校实时状态。

### 5.1 三张核心指标卡

1. **本学期咨询总人次**：显示当前学期咨询记录总数，并细分初访与复访。
2. **非正常评级学生**：显示“实时在册人数 / 历史累计人数”。实时人数代表当前仍处于非正常评级的在读学生；历史累计人数包含曾经进入非正常评级或在咨询记录中留下评级快照的学生。
3. **全校在读学生与健康率**：显示在读总人数、正常学生占比和非正常评级占比。

### 5.2 动态危机评级口径

首次使用或进入“系统设置 → 预警体系配置”，可选择“一级为最高危”或“三级为最高危”，并调整三个等级别名。默认显示如下；如果学校选择了另一种方向，颜色和排序会同步翻转，但历史数据不会被改写。

| 级别 | 颜色 | 系统含义 | 建议动作 |
|---|---|---|---|
| 重大（一级） | 🔴 红色 | 随时可能自伤/伤人或存在极高风险 | 立即按学校危机流程研判、支持、转介和留痕 |
| 严重（二级） | 🟠 橙色 | 中高风险，需要优先安排支持 | 纳入近期跟踪与家校/班主任协同 |
| 一般（三级） | 🟡 黄色 | 轻度适应问题或一般困扰 | 持续观察，必要时安排约谈 |
| 正常 | 🟢 绿色 | 当前无预警 | 保持日常支持和观察 |

学生档案内部仍保留旧字段用于兼容；概览和重点学生总表会通过评级 Store 解释映射。不要把“历史累计”误读成当前仍处于非正常评级。

### 5.3 概览图表

- **危机等级分布**：按当前配置的三个等级和正常显示人数与占比；
- **本学期主要问题归因**：按咨询记录中的问题分类统计；没有分类时显示“本学期暂无咨询分类归因数据”；
- **周/月报按钮**：在当前页 Modal 内预览和打印，不打开新窗口。

## 六、学生综合心理档案

### 6.1 学生列表筛选

学生档案中间列表支持：

- 姓名、学号、标签搜索；
- 年级筛选；
- 班级筛选；
- 兼容风险等级筛选；
- “包含非在读学生”；
- 危机程度高到低或低到高排序。

默认只显示在读学生。转出、休学和毕业档案不会被删除；勾选“包含非在读学生”后可以查到。

### 6.2 档案顶部操作

打开学生后，档案顶部显示姓名、学号、年级班级、累计咨询次数、当前危机等级、紧急联系人和标签。

- “导出单人完整档案卷宗”：打开当前页 A4 预览并可打印/另存为 PDF；
- “发起个体咨询”：打开新增 SOAP 记录；
- 危机预警等级下拉框：修改当前实时状态；
- 档案页签：服务履历、咨询历史、普查数据、编辑等。

### 6.3 医疗就诊与会谈存证

在服务履历页的“医疗就诊与会谈存证”卡片中：

1. 先填写附件备注，例如“2026-05-10 某医院诊断证明”或“三方会谈签名表”；
2. 点击“上传附件”；
3. 支持 PDF、JPG、JPEG、PNG，可一次选择多个文件；
4. 上传完成后，点击文件名或预览按钮查看；
5. PDF 在当前页 Modal 中预览，图片在当前页 Lightbox 中放大；
6. 修改备注后离开输入框即可保存；
7. 删除前确认已经完成备份。

### 6.4 学籍和特殊年级

系统根据入学年份、当前学年自动计算年级。留级、降级或其他特殊情况可以在编辑页开启“手动指定当前年级”，填写实际年级。

开启手动年级后，一键升学不会覆盖该学生的人工决定。学籍状态可以设置为在读、已转出、休学或已毕业。

## 七、重点学生与个案总表

在学生档案页面顶部切换：**👥 全校学生档案 / 📋 重点学生与个案总表**。它不是侧边栏孤立菜单，而是学生档案内的页签。

### 7.1 自动归集规则

只要满足以下任一条件，就会进入总表：

- 标准预警等级不是“无预警”；或
- `isIndividualCase` 被标记为个案辅导学生；或
- 学生存在个体咨询记录，系统会自动纳入个案范围。

总表不展示 SOAP 原文，只展示迎检所需的聚合字段。

### 7.2 筛选和字段

支持：

- 等级：全部、一级/红色、二级/橙色、三级/黄色、无/普通个案、其他；
- 年级；
- 班级；
- 学生姓名或学号。

表格字段：姓名、班级、预警/个案等级、主要困扰类型、最新辅导/留痕时间、就诊/会谈附件数、操作。

### 7.3 导出

- “导出当前总表 Excel”：导出当前筛选结果；
- “打印 / 导出 PDF”：在当前页打开 A4 台账预览；
- “单人卷宗”：进入某一学生的完整档案卷宗预览；
- 编辑按钮：跳回学生档案编辑页。

导出的重点学生总表仍属于内部资料，不应直接发到公开群或公众号。

## 八、个体咨询与 SOAP 记录

进入 **个体咨询**，可以按学生、问题分类和来访类型筛选。

### 8.1 新增咨询步骤

1. 点击“新增咨询”。
2. 选择学生；系统计算该生第几次咨询。
3. 选择来访类型：主动来访、教师转介或普查约访。
4. 填写日期、时长和问题分类。
5. 需要预约时填写预约日期和时间。
6. 依次填写 S、O、A、P。
7. 选择本次风险等级并保存。

### 8.2 SOAP 各字段怎么写

| 字段 | 建议内容 | 不建议写法 |
|---|---|---|
| S 主观陈述 | 学生自述的困扰、感受、事件和需求，尽量保留原意 | 直接替学生下诊断 |
| O 客观观察 | 可观察到的情绪、语言、行为、出勤或量表事实 | 只写“状态不好” |
| A 评估分析 | 基于当前材料的工作判断、风险线索和保护因素 | 把猜测写成确定结论 |
| P 后续计划 | 下一次联系、家校协同、转介、观察点和责任人 | 只写“继续关注” |

O 段支持使用本机保存的常用观察词模板。问题分类和观察词可在系统设置维护。

保存后，咨询记录会同步到学生档案、服务履历、概览统计和历史咨询列表。每条咨询会保存独立的“当次风险等级快照”，以后修改学生当前风险不会覆盖历史记录。

## 十二、附件存储边界：让长期运行保持流畅

系统支持本地附件，但不适合把几十兆视频全部转成 Base64 长期放进 IndexedDB。

### 12.1 医疗附件

- 学生档案医疗就诊与会谈存证支持 PDF、JPG、JPEG、PNG；
- 图片进入本地数据库前会自动缩放压缩；
- PDF 和图片可以在当前页预览；
- 单个附件超过 30MB 时不要强行上传。

### 12.2 留痕和素材附件

- 工作留痕支持图片、音频、视频和普通文件；
- 音频/视频超过 30MB 会被拦截；
- 备课素材单个文件不超过 8MB；
- 超大录音或视频应保存到学校批准的安全位置，在留痕正文中记录脱敏后的本地路径、文件名、时间和保管位置。

浏览器环境不能可靠提供真实本地路径给应用，因此路径引用必须由老师手动记录；不要把隐私文件上传到未批准的网盘。

## 十五、加密备份、恢复和自动备份

### 15.1 导出全量 `.mindbag`

1. 首次完成学生名单导入后；
2. 大批量普查导入前后；
3. 学期结束；
4. 换电脑或重装系统前；

### 15.3 恢复备份

恢复采用明确的两步流程：

1. 点击“选择备份文件并恢复”；
2. 点击虚线框，选择 `.mindbag` 或兼容 `.json`；
3. 查看备份时间、数据表数量、学生人数、咨询数量等摘要；
4. 输入主密码或 24 位恢复码；
5. 点击“开始解密并还原数据”；
6. 选择“覆盖恢复”或“合并恢复”；
7. 确认后等待应用刷新。

**覆盖恢复**：清空当前本地数据，再写入备份；适合新电脑迁移。
**合并恢复**：保留现有数据并按记录 ID 合并；适合补回缺失记录。

恢复前一定要先为当前数据再导出一份备份。恢复写入前系统会把每条记录转换为普通 JSON 对象，去除 Vue Proxy、函数、DOM 节点等不可写入值，避免 `DataCloneError`。

点击“仅清理模拟测试数据”。系统按 `isMock` 标记删除测试学生及测试业务记录，保留真实用户数据、学校配置、作息和教案。

### 16.3 恢复出厂

1. 先导出加密备份；
2. 点击“恢复出厂设置”；
3. 在二次确认框输入大写 `RESET`；
4. 点击确认；
5. 等待应用自动重载，重新完成首次设置。

恢复出厂会清空本地业务表和必要缓存，不能用来“撤销一次误删”。

## 十八、导出周报/月报并发布公众号文章

这是本项目推荐的安全工作流：

**工作台统计 → 脱敏报告 → AI 改写公众号稿件 → EasyFormat/135 排版 → 公众号草稿箱 → 人工审核发布**

### 18.1 在工作台生成脱敏周报/月报

1. 在概览面板点击“导出心理健康周/月报”；
2. 选择本周报表、本月报表或自定义时间段；
3. 检查报告时间范围；
4. 检查四张核心指标卡；
5. 检查预警分布、问题归因、趋势图、年级聚合表；
6. 点击“打印 / 另存为 PDF”。

报告只展示聚合数据，不展示学生姓名。打印采用当前页 Modal 和 `@media print`，不会打开新窗口。

### 18.2 把报告交给 AI 改写成公众号稿件

在 ChatGPT 中只粘贴脱敏后的统计数字和准备公开的教育内容。建议使用下面的提示词：

```text
你是一名中学心理健康教育公众号编辑。
请把下面的脱敏统计简报改写成一篇适合家长和教师阅读的公众号文章。

要求：
1. 不出现学生姓名、学号、班级、联系方式、咨询 SOAP、医院信息或可反推个体身份的细节；
2. 不把统计数据写成医学诊断结论；
3. 语气专业、温和、可行动，不制造恐慌；
4. 输出标题 3 个、摘要 1 个、正文小标题、段落正文、结尾行动建议；
5. 对所有数据使用“本校本阶段”“样本内”“聚合统计”等表述；
6. 给出 3 个配图建议，但不要生成或使用真实学生照片；
7. 保留以下数据，不擅自编造数字：

【在这里粘贴工作台导出的脱敏统计】
```

AI 输出后，老师必须逐项核对：数字是否与工作台报告一致、有没有把“人次”写成“人数”、有没有把“预警关注”写成诊断结论、有没有混入真实个案信息。

### 18.3 用 EasyFormat 或 135 排版

4. 检查标题层级、段落间距、引用和列表；
5. 添加不含学生身份的配图或插图；
6. 使用“复制到公众号”或复制富文本；
7. 粘贴到公众号后台编辑器；
8. 在公众号后台预览后保存为草稿。

5. 复制到公众号编辑器，或使用账号实际提供的同步功能；
6. 回到公众号后台检查后保存草稿。

不要把“排版完成”误认为“已经发布”。发布前仍要人工审核。

## 十九、四条最常用工作流

### 19.1 紧急接访

1. 顶栏搜索姓名或学号；
2. 打开学生档案，确认当前预警等级、历史风险和最近服务履历；
3. 点击“发起个体咨询”；
4. 填写 S/O/A/P 和本次风险快照；
5. 如有家校或领导协同，另建工作留痕并关联学生；
6. 按学校危机流程完成研判、转介和后续安排；
7. 当天导出或确认备份策略，不把原始个案材料发给第三方 AI。

### 19.2 普查后批量约访

1. 导入量表并检查预警原因；
2. 在批次详情勾选“仅看预警”；
3. 点击每名学生的“约访”；
4. 完成咨询 SOAP；
5. 必要时新增家校沟通留痕；
6. 在概览面板查看咨询人次和风险变化。

### 19.3 迎检前导出台账

1. 确认顶部当前学期；
2. 概览面板导出周/月报 PDF；
3. 学生档案 → 重点学生与个案总表，按需要筛选并导出 Excel/PDF；
4. 对单个重点学生打开档案，导出完整卷宗 PDF；
5. 检查所有文件的密级和存放位置；
6. 不把含身份信息的台账上传到公开网盘或公众号。

### 19.4 学期结束

1. 完成未结咨询、普查跟进和留痕；
2. 导出全量 `.mindbag` 并验证文件存在；
3. 检查自动备份最近执行时间；
4. 在学期与升学中建立下一学期；
5. 执行升学前确认毕业、转出和特殊年级学生；
6. 新学期开始后再次导出一份备份。

## 二十、常见问题排查

### 问题 1：换浏览器后数据不见了

数据按浏览器和设备隔离。换浏览器、清理站点数据或换电脑前必须先导出 `.mindbag`，在新环境中恢复。

### 问题 2：当前学期没有咨询或教学记录

检查顶栏当前学期。主列表按当前学期筛选；学生档案的全历史不受影响。

### 问题 3：同名学生不能新增

检查是不是学号重复或为空。系统允许同名，只要求学号全校唯一。

### 问题 4：导入普查提示重复

检查文件内部是否有重复学号，以及数据库中是否已经导入过同一学号。先清理表格，再重新预览。

### 问题 5：大视频无法上传

音频/视频超过 30MB 会被拦截。不要把原文件反复压缩后硬塞进数据库；保留安全本地路径引用，并在留痕正文写清文件名、时间和保管位置。

### 问题 6：恢复备份提示解密失败

确认密码或恢复码、文件后缀和文件完整性；不要把 `.mindbag` 当普通 JSON 修改。若仍失败，保留原文件副本和错误提示。

### 问题 7：恢复时报 DataCloneError

当前恢复服务已在写入前清理 Proxy、函数、DOM 节点和特殊值。若仍出现错误，停止重复恢复，重新导出一份新备份并记录具体文件名。

### 问题 8：飞书没有提醒

检查 Webhook、签名密钥、总开关、具体提醒开关、提醒时间和页面是否仍在运行；先发送测试卡片。

### 问题 9：打印报告打开了空白页

当前版本的报告和单人卷宗使用当前页 Modal + `window.print()`，不会打开新窗口。先关闭其他打印预览、刷新应用，再从原页面重新点击打印。

### 问题 10：删除后列表暂时不能点击

先等待本次删除事务完成并观察列表是否刷新；不要连续点击删除。若仍无响应，刷新应用；刷新不会清除 IndexedDB 数据。
