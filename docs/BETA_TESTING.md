# 心理老师工作台 Beta 真机实战测试包

这份材料用于招募 3–5 位一线心理老师，连续实操一周，观察真实工作节奏下的稳定性、可理解性和台账效率。测试数据应使用虚构学生或脱敏数据，不要把真实学生隐私材料发给开发者。

## 招募文案

### 小红书（哈喽老师）

> 正在招募 3–5 位一线学校心理老师，免费试用一周「心理老师工作台」Beta。
>
> 它是一个纯本地、离线优先的工作台，覆盖学生档案、个体咨询 SOAP、心理普查、团体辅导、教学记录、工作留痕、重点学生总表、加密备份和 PDF 台账导出。
>
> 我们想观察真实工作流里的几个高频瞬间：课前补打卡、临时接访、普查后批量跟进、迎检前 5 分钟导出台账。参与者只需要用虚构或脱敏数据连续试用 7 天，每天花 5–10 分钟填写反馈。欢迎私信「Beta」报名。

### 公众号（省思塔）

> 省思塔正在邀请 3–5 位一线心理教师参与「心理老师工作台」Beta 真机实战测试。
>
> 测试周期 7 天，覆盖学生档案、咨询 SOAP、普查导入、团辅、教学、工作留痕、加密备份与重点学生台账。测试全程使用虚构或脱敏数据，业务数据默认留在老师自己的电脑上。
>
> 如果你愿意用真实工作节奏试用，并反馈“哪里顺手、哪里卡顿、哪里容易误操作”，请回复「Beta」并留下常用系统（Windows 浏览器 / 安装版 / 便携版）。

## 一周测试安排

| 天数 | 建议动作 | 重点观察 |
| --- | --- | --- |
| 第 1 天 | 完成安全设置、学校/学期配置，导入 20–50 名虚构学生 | 首次启动、学号校验、搜索和筛选是否易懂 |
| 第 2 天 | 新增 3 条咨询 SOAP，编辑 1 条，删除 1 条 | 删除后输入框、列表和第三栏详情是否立即恢复 |
| 第 3 天 | 导入一批普查数据并完成 2 次快捷约访 | 表格列宽、预警原因、学生关联是否清楚 |
| 第 4 天 | 新增团辅、工作留痕、关联学生和附件 | 附件压缩、30MB 提示、分类数量与筛选是否一致 |
| 第 5 天 | 查看重点学生总表，导出单人档案和汇总报表 | 脱敏程度、打印排版、导出速度和文件命名 |
| 第 6 天 | 配置自动加密备份，导出并恢复一份测试备份 | 密码/恢复码、覆盖/合并恢复、恢复后数据完整性 |
| 第 7 天 | 模拟“迎检前 5 分钟”完成导表与打印 | 完成路径、等待时间、最容易迷路的按钮 |

## 收集与处理原则

- 只收集操作步骤、错误文本、脱敏截图和主观体验，不收集姓名、学号、咨询原文、联系方式或原始附件。
- 先记录“能否完成任务”，再记录“完成用了几步、等了多久、是否误操作”。
- 发现危机识别或记录安全问题时，立即停止用真实数据测试，按学校专业流程处理，不把软件反馈当作临床判断。
- 测试结束后由项目维护者汇总问题，按“阻断使用 / 高概率误操作 / 视觉瑕疵 / 建议”分级，不直接把单个老师的个案材料提交到仓库。
