# 阶段五：教学记录与设置中心

## 目标

1. 以本地 `lessonRecords` 原始记录管理心理课流程、反思和学生课堂观察。
2. 学生档案的服务履历实时汇总课堂观察，不复制或依赖独立事件表。
3. 以四页签设置中心集中管理分类词库、学期升学、应用锁与 `.mindbag` 备份恢复。

## 数据与联动

- `LessonRecord` 补齐班级、课堂观察、创建与更新时间；Dexie 升级兼容旧记录。
- `useLessonStore` 只按当前学期提供课程列表，保存或删除后通知全局学生版本。
- `StudentTimeline` 直接查询并合并被当前学生标记的课程记录；课堂观察节点使用 📚 图标。
- 课堂观察中的快捷约访写入短生命周期咨询上下文，交由既有咨询 Drawer 消费。

## 验证

- 生产构建需通过 TypeScript 与 Vite。
- 人工验收：新增一条课程记录、对一名学生快捷约访、在该学生档案确认课堂观察节点；检查四页签设置入口、锁屏与备份恢复。
