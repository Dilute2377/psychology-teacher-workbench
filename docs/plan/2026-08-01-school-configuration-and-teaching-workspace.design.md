# 学校配置与教学工作台重构设计

## 目标

以本机学校配置作为年级、班级、单双周和作息的唯一来源，消除依赖现有学生数据推测下拉项的逻辑；将零散备课素材与完整教案统一纳入教学工作台，并可关联到具体课时。

## 数据边界

- `src/constants/grades.ts` 固定 K-12 学段顺序、学段映射和排序工具。
- `settings` 中保存 `schoolProfile`：启用学段、各年级最大班级数、教学作息、授课周期。
- `lessonPlans` 继续保存完整标准教案；新增 `teachingMaterials` 保存视频、互动思路、PPT/讲义、风格设计等零散素材。
- `weeklySchedules` 关联 `lessonPlanId`，并可保存 `materialIds`、`cycle`（每周、单周、双周）与课程时长。

## 体验规则

- 所有年级选择项仅从 K-12 常量按学校配置读取，并严格按既定顺序排序。
- 班级选项由当前年级的最大班级数产生；学生现有数据不再决定下拉项是否存在。
- 个体咨询仅由用户明确点击记录、点击新增或跨模块传入咨询上下文时打开抽屉。
- 心理普查表格按班级、学号升序，支持年级、班级、预警状态组合筛选并避免换行。
- 教学工作台排除 `graduated` 学生对应班级；周课表可在单周/双周预览间切换，使用蓝/紫标记；素材与教案都可以一键安排到课时。

## 验证

1. `npm run build`。
2. 浏览器检查：咨询页初始不弹抽屉；普查筛选、排序和截断；教学单双周切换、素材安排上课、毕业班过滤；设置修改后选项同步。
